## Не переносить без отдельного решения

Пункт 23 в анализе помечен «не переносить как есть»: diff GDAL прячет ошибку преобразования и завязан на `SetFeature`, которого у нас нет. В таблице он оставлен `TODO`, чтобы решение `SKIPPED` было явным, а не потерялось. Код по нему не менять, пока статус не сменён на `SKIPPED` или не разобран заново по `ANALYSIS.md`.

Пункт 22 зависит от `TABFile::SetFeature`. Сейчас метод возвращает `OGRERR_UNSUPPORTED_OPERATION`. Патчи GDAL прикладывать не к чему, пока запись по идентификатору не появится отдельной задачей. Статус оставлен `TODO`.
